Innovative Feature: Smart Rental Home Matching

Rule-Based Weighted Engine

Nest Kerala incorporates a transparent, rule-based recommendation algorithm that dynamically calculates a match score (0% - 100%) for each property against user search preferences:

When exact criteria yield no matches, the system dynamically suggests the closest alternative homes with accurate badges (e.g. 95% Match, 88% Match).

Project Directory & Source File Index

Filename / Folder Type Description & Responsibility
index.html HTML5 / Root Main project index, launch portal, live server status indicator, and documentation hub.
app.py Python / Flask Core application controller, HTTP route handlers, authentication sessions, and REST endpoints.
models.py SQLAlchemy / ORM Relational schema: users, admins, owners, districts, properties, property_photos, reviews.
helpers.py Utility / Algorithm Smart Rental Home Matching algorithm (100% weighted score), auth decorators, file upload sanitizers.
seed_data.py Database Seeder Generates 14 Kerala districts, 56 unique rental homes, 336 photographs, 14 owners, reviews, and admin.
run.bat Batch Script One-click Windows launcher to start the Flask web server automatically.
templates/ Jinja2 Templates HTML templates: index.html, properties.html, property_detail.html, admin/, auth/.
static/ Static Assets Custom CSS styling, JavaScript interactivity, district banners, and property photographs.
instance/nestkerala.db SQLite Database Active relational SQLite database file with all pre-loaded seed records.
test_app.py Test Suite Automated test suite verifying auth, search, smart matching algorithm, and admin CRUD.
